# Python Calculator

Калькулятор с историей вычислений на Python.

## Что умеет
- Сложение, вычитание, умножение, деление
- Возведение в степень (**)
- Остаток от деления (%)
- Сохранение истории в файл
- Просмотр последних 5 вычислений
- Обработка ошибок ввода (буквы вместо цифр)

## Технологии
- Python 3.13
- Работа с файлами
- datetime

## Запуск
```bash
python calculator
